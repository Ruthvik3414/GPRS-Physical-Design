# GPRS Physical Design Implementation

## Project Overview
Backend Physical Design project focused on floorplanning, macro placement, power planning, and physical-design debugging using Cadence tools.

## Tools Used
- Cadence Innovus 23.16
- Cadence Genus
- Tcl scripting

## Work Completed
- Performed floorplanning, macro placement, and power planning.
- Resolved power-planning DRC shorts and connectivity errors through macro repositioning and power-routing modifications.
- Developed Tcl procedures for standard-cell area calculation and site-row/site-column dimension checks.
- Examined technology files, libraries, timing reports, and area reports.

## Current Status
Completed through placement and power-planning activities. Further physical-design stages are ongoing.
